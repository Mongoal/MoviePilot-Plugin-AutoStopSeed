# AutoStopSeed（自动停止做种）

MoviePilot **V2 插件**：自动停止 MoviePilot 创建种子的做种。支持两种互斥模式：

- **下载添加时设做种限制（默认）**：下载添加即给种子设置做种时间限制，由下载器自动计时停止，**不依赖整理**，下载完做种满设定分钟数即停。
- **整理完成时停止（可代替）**：文件整理完成时停止做种。

两种模式都**只作用于 MoviePilot 自己创建的种子**，文件不会被删除，可在下载器手动恢复。

## 为什么需要它

下载完成后 MoviePilot 会持续做种。带宽有限、分享率已达标、纯归档等场景希望入库后即停做种，但又不想删文件/种子。本插件按你选择的方式自动停做种。

## 工作原理

### 模式 B（默认）：下载添加时设做种限制

```
订阅/手动 下载添加 → 监听 DownloadAdded 事件，拿到 hash + downloader
                  ↓
        update_torrent(seeding_time_limit=N)   ← 一次性设置
                  ↓
        剩下交给下载器自身（无需轮询）
                  ↓
   下载完成 → 自动做种 → 做种满 N 分钟 → 下载器自动停止
```

- 复用 MoviePilot 链方法 `chain.update_torrent(seeding_time_limit=N)`，底层 qBittorrent / Transmission 的 `seeding_time_limit` 语义即「下载完成后做种满 N 分钟自动停」，计时起点是下载器判定的下载完成时刻。
- **不需要轮询、不依赖整理**——添加时设一次，结束。
- **rTorrent 不支持做种时间限制**（封装直接返回 False），用 rTorrent 请改用模式 A。

### 模式 A（可代替）：整理完成时停止

```
整理完成 → 监听 TransferComplete 事件
        ↓
list_torrents(hashs=[hash]) 复核（默认按内置标签过滤）
        ↓
同时校验两项：① 种子由 MP 创建 ② progress >= 100 整体下载完成
        ↓
都满足 → stop_torrents(hash)   任一不满足 → 跳过
```

为什么需要这两项校验：
1. **只管 MP 创建的种子**：`list_torrents` 默认按内置标签 `TORRENT_TAG`（默认 `MOVIEPILOT`）过滤，查不到的种子（qb 手动添加等）直接跳过。
2. **只停整体下载完成的种子**：整理与下载是独立环节，整理可能在**下载未完成时被手动触发**（如 10 集种子先下完 3 集就整理）。复用 MoviePilot 自身判断（`__is_torrent_download_completed`），未达 100% 一律跳过，避免误停卡死剩余内容下载（对应 issue #6009 同类问题）。

> MoviePilot 没有「下载完成」事件，整理完成是唯一隐含"下载已完成"语义的事件，故模式 A 必须靠它。

## 安装

把本仓库注册为 MoviePilot 插件市场仓库后安装：

1. MoviePilot → 设定 → 插件 → 添加插件市场，填入本仓库 GitHub 地址。
2. 在插件市场找到「自动停止做种」→ 安装 → 启用。
3. 按需选择模式与做种时长。

## 配置项

| 配置 | 说明 | 默认 |
|------|------|------|
| 启用插件 | 总开关 | 关 |
| 停止做种时机 | 「下载添加时设做种限制」或「整理完成时停止」 | 下载添加时设做种限制 |
| 做种时长（分钟） | 仅「下载添加时」模式生效，下载完做种满该分钟数自动停，0=下载完即停 | 1 |
| 操作后发送消息通知 | 设置/停止成功后推送一条消息 | 开 |

## 两种模式怎么选

| 你的情况 | 推荐模式 |
|---------|---------|
| 关了自动整理，或想要"纯下载做种控制" | **模式 B（默认）** |
| 开了自动整理，希望"整理入库后即停" | 模式 A |
| 用 rTorrent | 模式 A（rTorrent 不支持做种时间限制） |
| 想要"下载完立即停"（做种 0 分钟） | 模式 B，做种时长填 0 |

> 做种时长 0 = 下载完即停。注意部分 PT 站点有 HR（Hit and Run）考核，做种未达要求可能影响账号，请按站点规则设置。

## 常见问题

**Q：会不会删掉我的文件？**
不会。模式 A 调 `stop_torrents` 只暂停上传；模式 B 只设做种时间限制。文件与种子都保留。

**Q：会不会影响我用 qBittorrent 自己加的种子？**
不会。模式 A 靠内置标签复核排除；模式 B 监听的是 `DownloadAdded` 事件，该事件只在 MoviePilot 添加下载时发出，qb 手动加的种子根本不会触发。

**Q：模式 A 下载还没完成就手动整理会怎样？**
不会停种。未达 100% 的种子一律跳过，避免误停卡死剩余下载。

**Q：rTorrent 用模式 B 报"失败"是为什么？**
rTorrent 的 MoviePilot 封装不支持做种时间限制。请改用模式 A。

**Q：如何恢复做种？**
到下载器对相应任务点「继续」；模式 B 可在下载器里清除做种时间限制。
